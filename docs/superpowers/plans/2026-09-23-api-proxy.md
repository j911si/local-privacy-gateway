# API Proxy Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local HTTP proxy (`pgw-proxy`) that pseudonymizes Anthropic Messages API requests and restores responses, plus the session-continuation support in the core that it needs.

**Architecture:** see `docs/superpowers/specs/2026-09-23-api-proxy-design.md`. Core gets `GatewaySession` (persistent per-conversation mapping); the new package `privacy_gateway_proxy` holds pure transform functions, an SSE restorer with holdback, and a Starlette app that pipes requests to `httpx`.

**Tech Stack:** Python ≥ 3.12, `uv`; core deps unchanged; proxy group `starlette`, `uvicorn`, `httpx`. Tests: `pytest`, `pytest-asyncio` (dev), `httpx.MockTransport` for the fake upstream.

## Global Constraints

- Everything in the v0.1 plan's Global Constraints still applies (no values in findings/logs/exceptions; fail closed; TDD; ruff line length 100; commit trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`).
- `privacy_gateway/` must keep passing `tests/integration/test_no_network.py`. All network code lives in `privacy_gateway_proxy/`.
- Thinking / redacted_thinking blocks and `signature` fields are never modified in either direction.
- Run the suite with `uv run pytest -q`; proxy tests live under `tests/proxy/`.
