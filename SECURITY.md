# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | yes       |

Older versions receive no fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead: open the
[Security tab](https://github.com/j911si/local-privacy-gateway/security/advisories)
of this repository and choose "Report a vulnerability". A draft advisory keeps the
report private until a fix is released.

Useful in a report: affected version or commit, the component (`privacy_gateway`
core, `privacy_gateway_proxy`, vault, CLI), reproduction steps, and the impact you
see. Please use synthetic data only — never real personal data.

## Review history

Findings from past security reviews, including the ones still open, live in
[`docs/reviews/`](docs/reviews/).
